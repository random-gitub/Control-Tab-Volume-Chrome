# Control-Tab-Volume-Chrome
Controls the volume on a web page of a single page (tab) in Chrome when pressed.. Changes can be reverted by typing a new link or a new video, or by reloading the web page. Very useful

### 📂 How to Add This Whole Bookmark Folder in 2 Steps

Due to browser security settings, folders cannot be injected automatically. Follow these quick steps to import the entire folder into your browser:

1. **Download the file:** Click on the `bookmarks.html` file in this repository, then click the **Download raw file** button (the down-arrow icon) to save it to your computer.
2. **Import to Chrome:** Open a new tab in Chrome, paste `chrome://settings/importBookmarks` into your address bar, select **Bookmarks HTML File**, upload the file you just downloaded, and click **Done**.

*The entire folder and all its contents will immediately appear in your browser's Bookmarks bar under an "Imported" folder.*
